# Svelte Integration Specifications

## Data Structure
```javascript
const jobPosting = {
  // Basic Information
  id: string,
  title: string,
  company: {
    name: string,
    industry: string,
    size: string,
    description: string
  },
  location: {
    city: string,
    state: string,
    remote: boolean,
    hybrid: boolean
  },
  employment: {
    type: string, // full-time, part-time, contract
    level: string, // entry, mid, senior, executive
    salary: {
      min: number,
      max: number,
      currency: string,
      period: string // hourly, annually
    }
  },
  // Content Sections
  summary: string,
  responsibilities: string[],
  requirements: {
    required: string[],
    preferred: string[]
  },
  benefits: string[],
  // Application Details
  application: {
    instructions: string,
    deadline: string,
    contact: {
      email: string,
      phone: string,
      person: string
    }
  },
  // Metadata
  postedDate: string,
  updatedDate: string,
  source: string
}
```

## Component Architecture

### 1. **JobPostingHeader.svelte**
   - Job title, company, location
   - Salary and employment type
   - Posted date

### 2. **JobPostingSummary.svelte**
   - Lead paragraph with key highlights
   - Quick facts sidebar

### 3. **JobPostingContent.svelte**
   - Responsibilities section
   - Requirements section
   - Company information

### 4. **JobPostingApplication.svelte**
   - How to apply
   - Contact information
   - Deadline information

### 5. **JobPostingLayout.svelte**
   - Main container with newspaper styling
   - Column layout management
   - Responsive design

## CSS Classes

### Layout Classes
- `.newspaper-container`: Main wrapper
- `.newspaper-header`: Header section
- `.newspaper-columns`: Multi-column layout
- `.newspaper-column-left`: Left content column
- `.newspaper-column-right`: Right sidebar
- `.newspaper-footer`: Footer section

### Typography Classes
- `.headline-primary`: Main job title
- `.headline-secondary`: Company name
- `.byline`: Location and type info
- `.lead-paragraph`: Summary text
- `.body-text`: Main content
- `.sidebar-text`: Secondary information

### Component Classes
- `.job-header`: Header component styling
- `.job-summary`: Summary component styling
- `.job-content`: Main content styling
- `.job-application`: Application section styling

## Integration Workflow

1. Extract job posting content using analysis template
2. Transform content into structured data object
3. Pass data to Svelte components via props
4. Render with newspaper-style layout
5. Apply responsive design for mobile/desktop

## Responsive Design

- **Mobile**: Single column layout
- **Tablet**: Two-column layout with adjusted spacing
- **Desktop**: Full newspaper-style multi-column layout
- **Print**: Optimized for newspaper printing

## Accessibility Features

- Semantic HTML structure
- ARIA labels for screen readers
- Keyboard navigation support
- High contrast color scheme option
- Font size adjustment capability
