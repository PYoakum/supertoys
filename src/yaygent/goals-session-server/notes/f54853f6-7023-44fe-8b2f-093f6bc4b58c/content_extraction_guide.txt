# Job Posting Content Extraction Guide

## Content Checklist
- [ ] Job title and level
- [ ] Company name and industry
- [ ] Location (city, state, remote options)
- [ ] Employment type (full-time, part-time, contract)
- [ ] Salary/compensation range
- [ ] Key responsibilities (top 5-7)
- [ ] Required skills and qualifications
- [ ] Experience level required
- [ ] Application instructions
- [ ] Contact information
- [ ] Company description/mission
- [ ] Team structure
- [ ] Benefits package
- [ ] Growth opportunities
- [ ] Work environment/culture
- [ ] Preferred qualifications
- [ ] Application deadline
- [ ] Start date
- [ ] Company size
- [ ] Industry trends mentioned
- [ ] Technology stack
- [ ] Reporting structure
- [ ] Travel requirements
- [ ] Visa sponsorship

## Newspaper-Style Layout Structure

### 1. **Headline Section**
   - Job title (main headline)
   - Company name (subheadline)
   - Location and type (byline)

### 2. **Lead Paragraph**
   - Job summary (2-3 sentences)
   - Key selling points
   - Salary range if available

### 3. **Main Content Columns**
   - Left column: Job details, responsibilities
   - Right column: Requirements, company info

### 4. **Footer Section**
   - Application instructions
   - Contact information
   - Deadline information

## Information Hierarchy

### 1. **Primary (Most Prominent)**
   - Job title
   - Company name
   - Salary range
   - Location

### 2. **Secondary (Clearly Visible)**
   - Key responsibilities
   - Required qualifications
   - Application deadline

### 3. **Tertiary (Supporting Details)**
   - Company description
   - Benefits
   - Preferred qualifications

## Extraction Process

1. Read and identify all content sections
2. Extract information using the checklist
3. Categorize by importance level
4. Structure for newspaper-style presentation
5. Prepare for Svelte component integration

## Quality Assurance

- Verify all essential information captured
- Check for content completeness
- Ensure proper categorization
- Validate structure for web display
- Confirm readiness for app integration
