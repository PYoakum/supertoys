# Video Game Melody Composition Plan

## Basic Parameters
- **Duration**: 45 seconds (target length)
- **Style**: Classic arcade/chiptune inspired
- **Mood**: Upbeat and energetic
- **Key**: C Major (accessible and bright)
- **Tempo**: 120 BPM (moderate, game-friendly pace)

## Structure Breakdown
1. **Intro** (0-8 seconds): Simple lead-in with basic rhythm
2. **Main Theme A** (8-20 seconds): Primary catchy melody line
3. **Main Theme B** (20-32 seconds): Variation or counter-melody
4. **Bridge/Development** (32-40 seconds): Brief variation or build-up
5. **Outro/Loop Point** (40-45 seconds): Transition back to beginning

## Instrumentation
- **Lead**: Square wave synth (classic arcade sound)
- **Bass**: Simple bass line using triangle wave
- **Percussion**: Basic kick and snare pattern
- **Harmony**: Simple chord progression support

## Style Elements
- Simple, memorable melodic phrases
- Repetitive but not monotonous
- Clear rhythmic patterns
- Bright, energetic character
- Loop-friendly structure
- Limited note range for accessibility

## Chord Progression
- C - Am - F - G (classic pop progression)
- Simple and familiar to support melody

## Melodic Guidelines
- Use primarily C major scale notes
- Focus on stepwise motion with occasional leaps
- Create memorable hooks and phrases
- Ensure smooth transitions between sections
