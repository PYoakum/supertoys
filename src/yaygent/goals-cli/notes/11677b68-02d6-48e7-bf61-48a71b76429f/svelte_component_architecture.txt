## Core Components

### 1. NewspaperLayout.svelte
**Purpose**: Main layout container that orchestrates the entire newspaper structure

**Props**: 
- `jobPostings: JobPosting[]`
- `currentTheme: string`
- `layoutMode: 'desktop' | 'tablet' | 'mobile'`

**Responsibilities**:
- Manage responsive layout switching
- Handle global state management
- Coordinate data flow between sections
- Apply theme classes

**Implementation Example**:
```svelte
<script>
  import HeaderMasthead from './HeaderMasthead.svelte';
  import MainContent from './MainContent.svelte';
  import Footer from './Footer.svelte';
  
  export let jobPostings = [];
  export let currentTheme = 'professional';
  export let layoutMode = 'desktop';
  
  $: filteredJobs = filterJobs(jobPostings, activeFilters);
  $: featuredJobs = filteredJobs.filter(job => job.featured);
  $: standardJobs = filteredJobs.filter(job => !job.featured);
</script>

<div class="newspaper-layout {currentTheme}" data-layout="{layoutMode}">
  <HeaderMasthead />
  <MainContent 
    {featuredJobs} 
    {standardJobs} 
    {currentTheme}
  />
  <Footer />
</div>
```

### 3. JobCard.svelte
**Purpose**: Individual job posting card with variant styling

**Props**:
- `job: JobPosting`
- `variant: 'professional' | 'enthusiastic' | 'neutral' | 'cat-themed' | 'eldritch-horror'`
- `size: 'compact' | 'standard' | 'featured'`
- `showFullDescription: boolean`

**Features**:
- Dynamic styling based on variant
- Expandable descriptions
- Hover effects and animations
- Accessibility support
- Click handling for job details

**Implementation Example**:
```svelte
<script>
  export let job;
  export let variant = 'professional';
  export let size = 'standard';
  export let showFullDescription = false;
  
  $: cardClasses = `job-card ${variant} ${size}`;
  $: truncatedDescription = job.description.slice(0, 150) + '...';
</script>

<article class="{cardClasses}" on:click={handleCardClick}>
  {#if job.urgent}
    <span class="urgent-badge">URGENT</span>
  {/if}
  
  <h2 class="job-title">{job.title}</h2>
  <h3 class="company-name">{job.company}</h3>
  
  <div class="job-description">
    {#if showFullDescription}
      {@html job.description}
    {:else}
      {truncatedDescription}
    {/if}
  </div>
  
  <div class="job-metadata">
    <span class="location">{job.location}</span>
    <span class="salary">{job.salary}</span>
    <span class="type">{job.type}</span>
  </div>
  
  <div class="job-posted">
    Posted: {formatTimeAgo(job.postedDate)}
  </div>
</article>
```

## State Management

### Svelte Stores
```javascript
// stores.js
import { writable, derived } from 'svelte/store';

export const jobPostings = writable([]);
export const activeFilters = writable({
  location: '',
  type: '',
  salary: '',
  tags: []
});
export const currentTheme = writable('professional');
export const layoutMode = writable('desktop');
export const searchQuery = writable('');

export const filteredJobs = derived(
  [jobPostings, activeFilters, searchQuery],
  ([$jobPostings, $activeFilters, $searchQuery]) => {
    return filterJobPostings($jobPostings, $activeFilters, $searchQuery);
  }
);
```

## Component Communication Patterns

### Parent-Child Communication
- Props for data down
- Events for actions up
- Slots for content projection

### Global State Management
- Svelte stores for shared state
- Context API for component trees
- Event dispatching for cross-component communication

### Data Flow Architecture
1. App.svelte manages global state
2. NewspaperLayout.svelte coordinates layout
3. Section components handle data distribution
4. JobCard components render individual items
5. UI components provide reusable interactions

This architecture provides a scalable, maintainable foundation for the newspaper-style job board application while supporting all five job posting variants and responsive design requirements.
